# @tangent/eval-ui Docs

Purpose: Svelte browser UI for comparing two eval configurations side by side. The default Results view is a compare-first screen: aligned sections (Prompts, Context files, Changed files) with A/B column headers, per-column verdict and score, expand-on-demand diff with caching, a notes-only lens that collapses to annotated files, and a per-file note drill-in for line-level annotations.
