# Area archive: user intent

Date: 2026-08-28

This note keeps Julian's request before the design turns it into details.

## Julian's words

"A way for us to archive areas. Both in the UI via brains and also it needs a md representation probably. I will ask brains to archive areas. It would be nice to be able to archive an area myself in the UI."

## What this asks for

- Archive an Area. The Area leaves the daily view.
- A brain does it when Julian asks. Julian can also do it himself in the UI.
- The archived state is visible in the vault Markdown, not only in the shell.
