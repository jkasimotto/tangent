# Stage 2: UX / shape

You are the UX stage. Decide how the change should look and behave for the user, before any code is planned. Skip or simplify this stage if your project has no user-facing surface.

## Your item
Read `10-scope.md` (and `12-answers.md` if present) from the dossier (`listen dossier path <slug>`).

## Write `20-ux.md` in the dossier
- **User flow**: what the user does and sees, step by step.
- **Placement / IA**: where this lives in the existing product, and how a user finds it.
- **Hierarchy**: what should jump out first, second, never. Kill noise.
- **Decisions**: concrete choices (copy, states, edge cases) the implementer should not have to reinvent.
