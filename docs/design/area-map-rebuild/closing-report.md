## The done condition, clause by clause

**"No component owns the whole Map."** Proved. `MapRoot.tsx` is 159 lines, under the design's own 200. The largest production module under `app/map/` is `kernel/kernel-world-types.ts` at 388 lines, and the `module-size` lint fails the tree at 401. No file in the Map is near the 3,273 lines of `area-map-world.jsx`, which `9a522a04` deleted along with its entry and stylesheet.

**"One authority answers what a pointer press means, with Excalidraw subordinate to it."** Proved. `meaningOfPress` has exactly one production caller, `map-root/map-root-canvas.ts:112`, and `hitTest` has exactly one, the same file at line 74. `input/press-meaning.property.test.ts` proves the function total and deterministic, proves it never names an Area that fold or scope hid, proves Space always pans, proves a press inside a Block never moves that Block's Area or an ancestor, and proves a rotation handle is refused. The `selection-write-confinement` lint holds `selectedElementIds` to `input/excalidraw-subordination.ts` and `canvas/projection.ts`, and the `pointer-confinement` lint holds Excalidraw's pointer callbacks to `canvas/MapCanvas.tsx`. Both lints pass over 160 files.

**"Values the code mints are proved by property test to satisfy the guards the code applies."** Proved. `public/area-map-wire-values.js` registers nine pairs: `worldRevision`, `treeRevision`, `worldId`, `resourceId`, `runtimeId`, `regionId`, `operationId`, `gestureId` and `shardRevision`. The property test mints ten thousand values per entry and asserts the guard accepts each, and asserts each guard rejects the empty string, a leading dash, a leading underscore and a value over its cap. Twenty-one tests pass. Seven server and browser modules now import their guards from that registry, including `area-map-world-index.mjs`, `area-resource-mutations.mjs` and `public/area-map-world-controller.js`. The `wire-guard-confinement` lint checks 353 files and holds an id-shaped regex to the registry, with ten wider-scope files still in the ratchet.

**"Layout constants are named once."** Proved for TypeScript, not for CSS. `layout/layout-tokens.ts` is the one owner in code, `no-unnamed-number` passes over 125 files with only `units/` and `layout-tokens.ts` exempt, and `layout/layout-tokens.test.ts` asserts that every `--tangent-map-*` property `map.css` reads is one the table emits, that `map.css` defines none of its own, and that every media query width in `map.css` is a breakpoint the table names. What is not held is every other number in the stylesheet. See "Numbers and styles outside the owners" below.

A copy of the vault at commit `fcbe2b02` was served by the unmodified production server: 56 Areas reported by the world, 56 by the server, 56 region elements composed, 56 held by Excalidraw, 0 Areas with no region and 0 shards that failed to read, 0 page errors. ## What the design promised that the lint kit does not cover

- **Numbers in the stylesheet.** The design says `layout-tokens.ts` is the only file with layout numbers. `ui/map.css` holds 106 `px` literals: gaps, padding, radii, minimum heights and outline widths. No lint reads numbers in CSS. `no-unnamed-number` parses TypeScript and JavaScript only.
- **A module guide in every directory.** The structure section says every directory under `app/map/` carries an `AGENTS.md`. The `require-module-agents` lint only demands one where a directory holds five or more production files, and 8 of the 20 directories have none: `layout`, `legacy`, `surfaces/announce`, `surfaces/find`, `surfaces/help`, `surfaces/kinds`, `surfaces/outline` and `surfaces/placement`.
- **The scope of the number and confinement lints.** The design table names `public/area-map-world-core.js` as an exception to `no-unnamed-number`, which implies the lint reaches `public/`. It does not. `no-raw-number`, `no-unnamed-number`, `no-any` and every confinement lint run over the strict scope only, which is `app/map/` and `scripts/lint/`. Only `function-size`, `module-size`, `no-long-param-list`, `no-junk-drawer-modules` and `wire-guard-confinement` reach the wider scope. That matches the decision not to convert the kernel, but the table's exception column reads as though the kernel were checked and it is not.
- **One authority, as a rule a lint enforces.** Nothing mechanically stops a second module computing its own press meaning or its own hit test. The rule holds today, and I verified it by call graph rather than by lint: one production caller each for `meaningOfPress` and `hitTest`. What the lints do enforce is the consequence, that only `excalidraw-subordination.ts` and `projection.ts` write the selection and only `MapCanvas.tsx` takes Excalidraw's pointer callbacks.
- **One file for copy.** The design names `copy.ts`. The sentences live in fourteen files under `copy/`, re-exported through `copy.ts`. The `copy-confinement` lint reads JSX and exempts `copy.ts` and `ui/`, so the split is invisible to it. This is a documentation drift, not a defect.
- **The structure the design drew.** The implementation adds `map-root/` with 17 files and 3,092 lines, plus `mount-options.ts`, `layout/branch-priority.ts` and `surfaces/kinds/`. `MapRoot.tsx` stayed under 200 lines because its composition moved there. No single file owns the Map, so the cause is still gone, but `code.md` describes a tree that no longer matches what was built.

## Files over the limits

None. Every production module under `app/map/` is at or under 388 lines against a 400 cap, every function is under 80 lines, no function takes more than seven parameters, and no production `any` exists. The `module-size` and `function-size` lints check 394 files each and pass with no grandfathering inside the strict scope. The ratchets that remain are all outside the Map: 52 files in `function-size`, 28 in `module-size`, 2 in `no-long-param-list` and 10 in `wire-guard-confinement`, every one of them a pre-existing server or `public/` module.

## Numbers and styles outside the owners

- No raw hex, `rgb` or `hsl` outside `ui/tokens.css`, and no `z-index` outside `ui/layers.css`. I checked by grep as well as by lint, and both are clean.
- Four inline styles exist and all are inside the allowed owners. `MapRoot.tsx:96` emits the layout tokens, which is the one the design allows. `ui/Panel.tsx:45` applies the panel width constant. `ui/CanvasLabel.tsx:53` and `:71` write `left` and `top` from a computed scene point. The last two are positioning written in TSX rather than CSS. They are legitimate, because the value changes per label and per frame, but they are the one place where positioning is not in a stylesheet, and the `no-freestanding-position` lint exempts the whole kit rather than that case.
- `ui/map.css` line 15 sets `--tangent-current-panel-inset: 0px` as the default, which is a number in CSS by necessity. The other 105 `px` literals in that file are the unheld ones described above.

## The two suite failures, stated plainly

- `area-map-resources-server-browser` fails today and the rebuild did not cause it. The assertion is that copying paths never writes the vault. What writes the vault is the server seeding a starter `map-kinds.md` and thirteen icon drawings when the Map first reads `/api/areas/map-kinds`, and I proved with a bare `fetch` and no browser that the request alone produces the commit. The old component fetched the same route on mount, at line 659 of the deleted `area-map-world.jsx`, so the suite would have failed at `45a68759` in the same place. The audit's list of pre-existing failures does not name it, so it became red between the audit and now. The technical contract line "the existing browser suites pass unchanged" is therefore not true today, and this deserves its own Goal: opening a Map should not commit to the vault.
- `area-map-ui` cannot run in this worktree at all, for the missing `d3-*` packages under `app/node_modules`. It does not exercise the rebuilt Map, and the contract line that names it is unverified here rather than failing.

## The short answer

The four causes are gone. No component owns the Map, one pure function answers what a press means with Excalidraw subordinate to it, every minted value is proved against its own guard, and every layout number in code is named once. Of the eleven bullets the audit left open, five are proved fixed with tests that survive a refutation attempt, and the toast is proved as half of the bullet it shares with the failure codes. Three are half fixed, with red tests committed as honest markers. Two, the dead-end recovery buttons and the failure codes as headlines, have the structure and the words but no browser proof. One, the rubber band inside an Area, waits on Julian. The work that remains is three small fixes with tests already written for them: inset the camera fit and the placement preview by the retained panel, fold on the Space keyup only when no drag ran, and let ArrowDown reach the picker's list.
