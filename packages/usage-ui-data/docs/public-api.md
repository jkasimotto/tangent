# @tangent/usage-ui-data Public API

Public import paths:
- `@tangent/usage-ui-data`

Important exports:
- `UsageUiClient`
- `createUsageApiClient`
- `createUsageUiClient`
- `UsageUiClient.getCockpit(id)` returns `UsageCockpitView`.
- Cockpit DTOs and pure mappers: `UsageCockpitView`, `buildUsageCockpitView`, `buildSessionFinderView`, `buildSessionStoryline`, `buildTraceWaterfall`, `buildTranscriptHighlights`, and `buildDiagnosticCards`.
- Usage session, timeline, transcript, metrics, provider, and message-selection DTOs.
